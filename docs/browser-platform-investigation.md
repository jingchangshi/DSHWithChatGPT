# Browser platform decisions

The primary Windows deployment uses dedicated Chrome, DirectCdpPrimitives and a semantic Sidecar. Browser Harness remains a compatibility transport over the same ChatGptWebDriver. Transport code records target/document/epoch and complete bounded history; internal conversation-binding rules interpret routes and exact outgoing proof. Browser primitives do not own conversation promotion policy.

Missing body and unresolved App rendering are local observations within existing bounded windows, never durable workflow state or proof. An absent user may permit the existing single fenced materialization load; a mismatched/ambiguous proof never permits resend. Only exact App + digest + unique last-user proof allows adoption.
